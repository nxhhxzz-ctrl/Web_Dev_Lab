# Web Dev Lab

A collection of standalone HTML pages for practicing web development. The pages use HTML and CSS and can be opened directly in a web browser.

## Pages

- `program/P5.html` — Personal biography page
- `program/P6.html` — Personal portfolio
- `program/P7.html` — Design tokens and typography
- `program/P8.html` — Sticky navigation and card overlay
- `program/P9.html` — Responsive navigation and cards
- `program/P10.html` — Portfolio header and footer
- `program/P11.html` — Newspaper layout
- `program/P12.html` — Portfolio projects grid
- `program/P13.html` — Portfolio projects grid

## View a page

Open any `.html` file in a web browser. No installation or build step is required.
